# 🛒 CartBuddy

CartBuddy is a personal shopping list API designed to register and manage purchased items.

The first version (V1) focuses on a simple and well-structured implementation that allows users to:

- Create shopping lists
- Add items to a shopping list
- Retrieve shopping lists with their items
- Delete shopping lists

At this stage, the API does **not** handle price tracking, quantity management, or analytics. The goal of V1 is to establish a clean and scalable backend foundation that can evolve over time.

---

## 🚀 Tech Stack

### Node.js

JavaScript runtime used to build the backend application.

### TypeScript

A typed superset of JavaScript that improves maintainability, scalability, and developer experience through static typing.

### NestJS

A progressive Node.js framework that provides:

- Modular architecture
- Dependency injection
- Clear separation of concerns
- Scalable and testable structure

NestJS helps keep the project organized from the beginning, making it easier to expand in future versions.

---

## 🎯 Purpose

CartBuddy V1 is a foundational backend project focused on:

- Clean architecture principles
- Proper domain modeling
- Structured API development

It is built as a study and practice project using Node.js, TypeScript, and NestJS.
